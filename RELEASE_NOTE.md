# Qbnox SMTP Plugin v2.1.0 - Release Note

We're excited to announce the latest update to **Qbnox Systems SMTP Plugin** - an enterprise-grade email solution for WordPress!

## 🎯 What's New

### Improved Documentation & Installation
- **New Bedrock Support**: Added Composer-based installation for modern WordPress workflows using Bedrock by Roots
- **Streamlined Installation Guide**: Reorganized documentation with four clear installation options to suit different workflows
- **Developer Resources**: Separated developer setup instructions into DEVELOPERS.md for cleaner documentation

### Installation Options
1. **Bedrock (Recommended)** - Composer-based: `composer require ugenkudupudiqbnox/qbnox-smtp`
2. **WordPress Admin Upload** - Download and upload via admin panel
3. **Manual Installation** - FTP/file manager upload
4. **Source Installation** - Direct GitHub clone for advanced users

## ✨ Key Features

- 🚀 **Enterprise SMTP** - Reliable email delivery
- 🌐 **Multisite Support** - Network-wide configuration
- 🔐 **OAuth Authentication** - Secure modern email providers
- 📊 **Email Analytics** - Track delivery, opens, and engagement
- 🔔 **Webhook Integration** - Real-time support for Amazon SES and Brevo
- 🧪 **Test Email Diagnostics** - Built-in troubleshooting tools
- 📝 **Email Logging** - Comprehensive debugging logs

## 📋 Requirements

- WordPress 6.0+
- PHP 8.0+
