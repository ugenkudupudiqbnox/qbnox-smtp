**Qbnox SMTP Plugin v2.1.0 Now Available! 📧**

We're pleased to announce an update to the Qbnox Systems SMTP Plugin - an enterprise-grade email solution for WordPress and Pressbooks!

**What's New:**
✅ Bedrock/Composer support (recommended installation method)
✅ Improved installation documentation with 4 clear options
✅ Separated developer resources for cleaner docs

**Key Features:**
• Enterprise SMTP with reliable delivery
• Multisite support for network-wide configuration
• OAuth authentication for modern email providers
• Email analytics (track delivery, opens, engagement)
• Webhook integration (Amazon SES & Brevo)
• Test email diagnostics & logging tools

**Requirements:** WordPress 6.0+ | PHP 8.0+

**Install via Composer (Bedrock):**
```
composer require ugenkudupudiqbnox/qbnox-smtp
```

**Download:** [GitHub Releases](https://github.com/ugenkudupudiqbnox/qbnox-smtp/releases)

Perfect for Pressbooks installations requiring professional email delivery! Questions? Open an issue on our GitHub repository.
